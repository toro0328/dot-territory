# こもれび開拓団（RPG試作）

ドット調のマップを歩き、土地を開拓・占領しながら、最初の拠点の家を飾るブラウザーゲームです。HTML/CSS/JavaScriptで動きます。

## 試せること

- 初回起動時の冒険者名登録
- マップ上の目的地を選ぶと、道に沿って時間をかけて自動移動
- 無人地の開拓（到着後30秒）／他の人の土地の占領（到着後60秒から）
- 以前の自分の土地の奪還（到着後15秒）
- 中断した同じ土地への再挑戦は、1回ごとに占領時間が30秒延長
- 最初の拠点にある家の室内を表示し、購入した家具を配置・移動
- 家に配置した家具の種類に応じて、土地収入にボーナス
- 気力の消耗と時間による回復、土地の購入
- 進行状況をブラウザーの `localStorage` に保存

## ローカルで起動

`index.html` をブラウザーで開くか、このフォルダーで次を実行します。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 現在の制限

これは遊び心地を見るための試作です。各ブラウザーは独立した世界を持ち、名前・土地・ポイントは他の端末と共有されません。表示される他プレイヤーや土地は見本データです。100人で同じ世界を遊ぶには、認証、共有データベース、同時更新の衝突処理、サーバー側の時間判定が必要です。

防衛設備の効果、レイド、継続的なランダム土地生成、休眠アカウント処理も未実装です。
