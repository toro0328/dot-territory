# こもれび開拓団（試作）

スマホで遊べる、ドット絵の土地開拓・陣取りゲームのブラウザ試作です。HTML/CSS/JavaScriptだけで動きます。

## 試せること

- 矢印キー、画面の十字ボタン、隣のマスのタップで移動
- 無人地の開拓（30秒）
- 他の人の土地への占領（60秒、同じ土地への中断した再挑戦ごとに+30秒）
- 以前の自分の土地の奪還（15秒）
- 気力の消耗と時間による回復
- 土地の購入、飾りの購入、飾りによる収入ボーナス
- 進行状況をブラウザの `localStorage` に保存

## ローカルで起動

`index.html` をブラウザで開けば起動します。開発用サーバーを使う場合は、このフォルダで次を実行します。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## GitHub Pages で試す

リポジトリの **Settings → Pages** で `Deploy from a branch` を選び、ブランチ `main`、フォルダ `/ (root)` を指定して保存します。Pages公開後は、リポジトリの設定画面に表示されるURLから試せます。

## 現在の制限

これは操作感を見るためのローカル試作です。各端末はそれぞれ独立した世界を持ち、プレイヤー名や土地、ポイントは他の端末と共有されません。100人で同じ世界を遊ぶには、認証、共有データベース、同時更新の衝突処理、サーバー側の時間判定が必要です。ゲーム画面に秘密鍵を置かずに使えるオンライン保存先を次の段階で接続します。

このデモではマップの住人・土地は見本データです。防衛設備、レイド、ランダムな土地の継続生成、休眠アカウント処理はまだ動作しません。
